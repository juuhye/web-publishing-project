# 코카콜라 리디자인

코카콜라 브랜드 사이트를 **메인 · 히스토리 · 패밀리** 3개 페이지로 리디자인하고 퍼블리싱한 개인 프로젝트입니다.
페이지마다 다른 인터랙션(세로 슬라이더, 풀페이지 스크롤, 드래그 앤 드롭)을 적용해 브랜드 이야기를 보여주도록 구성했습니다.

**디자인부터 퍼블리싱, 인터랙션 개발까지 모든 과정을 혼자 작업했습니다.**

> 개인 포트폴리오용 작업물이며, 코카콜라 공식 사이트와 관련이 없습니다. 브랜드 로고 · 제품 이미지의 저작권은 The Coca-Cola Company에 있습니다.

## 작업 범위

| 단계       | 작업 내용                                                                 |
| ---------- | ------------------------------------------------------------------------- |
| 디자인     | 3개 페이지 구성, 레이아웃 · UI 디자인, 페이지별 인터랙션 설계              |
| 퍼블리싱   | HTML 마크업, CSS 스타일 · `@keyframes` 애니메이션                          |

## 사용 기술

- **HTML5 / CSS3**: `@keyframes` 애니메이션, `transition`
- **jQuery**: 스크롤 · 마우스 이벤트, `animate()` 인터랙션
- **jQuery UI** + **Touch Punch**: 패밀리 페이지 드래그 앤 드롭 (`draggable`, `droppable`)
- **Swiper 8**: 메인 비주얼 세로 슬라이더, SNS 카드 슬라이더
- **fullPage.js 3**: 히스토리 페이지 섹션 단위 스크롤
- 웹폰트: **Gmarket Sans**, Exo 2, Nunito Sans, Mulish

<br>

## 페이지별 인터랙션

### 메인 ([js/main.js](js/main.js))

- 비주얼: Swiper `direction: "vertical"` 자동 재생 슬라이더. 슬라이드마다 텍스트와 제품 이미지가 `@keyframes`로 순서대로 등장
- 브랜드 그리드: 스크롤이 그리드 영역에 들어오면 배경 애니메이션 실행, 마우스를 올리면 카드 정보 노출
- 병 이미지가 흔들리며 떠오르는 동작을 반복하는 애니메이션 (`ani_bottle`)
- 브랜드 영상은 음소거 · 자동 재생 · 반복 재생으로 삽입
- SNS 영역: 3개씩 보이는 무한 루프 슬라이더

### 히스토리 ([js/history.js](js/history.js))

- fullPage.js로 섹션 단위 스크롤, 각 섹션에 앵커(`#page01` ~ `#page09`) 지정
- `afterLoad` 콜백으로 섹션에 들어갈 때 이미지가 슬라이드 · 페이드인 되고, 섹션을 벗어나면 초기 상태로 되돌림
- 1893년 · 1905년 섹션은 이미지를 클릭하면 병 디자인이 바뀌는 클릭 인터랙션
- 1931년 산타클로스 광고 섹션은 영상이 섹션 진입 시 자동 재생 (`data-autoplay`)

### 패밀리 ([js/family.js](js/family.js))

- 제품 로고에 마우스를 올리면 캔 이미지가 아래에서 올라옴
- 제품을 오른쪽 영역에 끌어다 놓으면 해당 제품의 성분 · 맛 종류 · 영양 성분표 팝업 노출
- `revert: true`로 놓은 뒤 제품이 원래 자리로 돌아가고, 드래그 중에는 안내 문구에 애니메이션 적용
- Touch Punch로 터치 기기에서도 드래그 가능

## 작업하며 신경 쓴 점

### 웹 접근성

- 로고 링크는 `.blind` 텍스트로 대체 텍스트 제공
- 닫기 버튼 이미지에 `alt="팝업 닫기"` 지정
- 이미지로만 이루어진 링크(SNS 아이콘, 이동 버튼)와 제목 이미지, 제품 로고에 대체 텍스트 제공

### 마크업 · 스타일

- 클래스명은 snake_case로 통일하고, 번호 대신 내용을 나타내는 이름 사용 (예: `.list02` → `.brand_company`, `.visual01` → `.slide_coke`)
- 약어 규칙 통일: 제목 `tit`, 설명 `des`, 텍스트 `txt`, 감싸는 요소 `wrap`
- 상태 클래스는 `.on` 하나로 통일 (활성 · 노출 · 애니메이션 시작)
- 이미지는 페이지별 폴더로 나누고 `종류_대상` 형식으로 이름 지정 (예: `logo_zero.png`, `can_zero.png`, `table_zero.png`, `bg_sec02.png`)
- 히스토리 섹션은 연대 순서가 곧 내용이라 `.sec01` ~ `.sec09`로 번호를 유지하고, 하위 요소도 `.sec03_img`처럼 같은 접두어 사용
- `reset.css` → `keyframes.css` → `common.css` → 페이지별 CSS 순으로 불러오도록 통일
- 헤더 · 푸터 · 버튼 스타일은 `common.css`에 모아 세 페이지에서 공통으로 사용
- 애니메이션은 `keyframes.css`에 따로 모아 관리
