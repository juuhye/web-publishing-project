# CRYPTO POOL 랜딩 페이지 퍼블리싱

디지털 자산 관리 플랫폼 CRYPTO POOL의 서비스 소개 랜딩 페이지를 퍼블리싱한 작업물입니다.
서비스 개요부터 파트너까지 10개 섹션을 한 페이지에 구성하고, 스크롤에 따라 콘텐츠가 순서대로 나타나도록 했습니다.

> 페이지 내 텍스트 · 수치는 클라이언트 제공 콘텐츠이며, 투자 권유와 관련이 없습니다.

<br>

## 사용 기술

- **HTML5 / CSS3**: Flexbox, CSS counter, `backdrop-filter`, `@keyframes`
- **Vanilla JS**: 스크롤 방향에 따른 헤더 노출, 모달 팝업
- **AOS 2.3.4**: 스크롤 등장 애니메이션
- **Pretendard** 웹폰트 (woff2)

<br>

## 주요 기능

- **헤더**: 아래로 스크롤하면 숨고, 위로 스크롤하면 반투명 고정 헤더로 다시 나타남 (`requestAnimationFrame`으로 스크롤 처리)
- **GNB**: 앵커 링크 + `scroll-behavior: smooth`로 섹션 이동
- **모달**: 언어 선택 · 앱 다운로드 버튼 클릭 시 "서비스 준비중" 팝업. ESC · 배경 클릭으로 닫기, 열고 닫을 때 포커스 이동
- **카드 번호**: `counter()`로 카드 순번(01, 02 …)을 CSS에서 자동 생성

<br>

## 작업하며 신경 쓴 점

### 웹 접근성

- 제목 계층을 `h1`(로고) → `h2`(섹션 제목) → `h3`(소제목) 순서로 정리
- 정보를 담은 이미지(수익 그래프, 추천 구조도)에 대체 텍스트 제공, CSS 배경으로 들어간 그래프 범례는 `.blind` 텍스트로 보완
- 장식용 이미지는 `alt=""`로 스크린리더에서 제외
- 로고 · 닫기 버튼 등 텍스트 없는 링크에 `.blind` 텍스트 제공

### 성능

- 섹션 배경 이미지를 PNG → WebP로 변환 (약 19MB → 1MB)
- 모든 `<img>`에 `width` / `height`와 `loading="lazy"` 지정해 레이아웃 밀림 방지
- 웹폰트는 woff2만 사용
